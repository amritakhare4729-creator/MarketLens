How MarketLens Uses Machine Learning

MarketLens evaluates different machine-learning approaches rather than assuming that one model is always superior. The models are evaluated on historical test data using appropriate performance metrics.

Classification

Predicts whether the next trading day's return is positive or negative.

Regression

Attempts to estimate the next-day percentage return of a stock.

Baseline Comparison

Model performance is compared with simple baseline approaches to avoid presenting weak models as reliable predictors.
