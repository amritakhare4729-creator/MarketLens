How to Read Sector Analysis

These metrics are descriptive indicators of historical market behaviour. They should be used together rather than interpreted in isolation.

Average Daily Return

Measures the average percentage change in daily closing prices for companies within a sector. Positive values indicate positive average daily performance during the analysis period.

Average Volatility

Measures recent variation in daily returns using the 20-day volatility feature. Higher values indicate greater recent price fluctuation.

Trading Volume

Shows the average number of shares traded. Higher trading volume generally indicates greater trading activity within the sector.
